Getting Started

新手指引

平台功能

通过 Agent 生成 480x360 小屏应用，先在网页右侧预览，再由你确认是否部署到硬件。

创建项目

点击左上角“新建”，输入项目名称。项目会出现在左侧列表，并在刷新后继续保留。

生成应用

在聊天框描述要做的硬件应用。Agent 会理解需求、生成文件、执行本地或 Runner 验证。

Runner 与硬件执行

公网部署后，Python 会优先交给服务器 Runner 执行；Runner 不可用时仍保留网页预览。

应用市场

应用市场支持“预览”和“一键部署”。预览会创建新项目，可继续和 Agent 对话修改。

失败日志

任务失败时，先看聊天区给出的技术详情、失败阶段和操作按钮，再决定重试或反馈。

Credits / Usage

当前公测阶段免费使用；Usage 会保留用量入口，后续接入 Credits 计费。

支持板子

当前重点支持泰山派 RK3566 透明版、灰色版和亮黑版。其他开发板后续会在主控界面选择。
